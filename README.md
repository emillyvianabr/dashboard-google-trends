# Dashboard Google Trends — Bondinho / Pão de Açúcar

Versão premium do dashboard para GitHub Pages.

## Arquivos
- `index.html`
- `bondinho-premium.css`
- `bondinho-premium.js`
- `data.js` (fallback)
- `data/dados.xlsx` (fonte oficial)

## Atualização
Para atualizar os dados publicados, substitua apenas `data/dados.xlsx` mantendo o mesmo nome e a estrutura das abas.
