# Google Trends - Análise de Interesse do Parque Bondinho

Projeto estático para GitHub Pages.

## Arquivos necessários
- `index.html`
- `style.css`
- `app.js`
- `.nojekyll`
- `data/dashboard-data.js`

## Publicação
Envie todos os arquivos e a pasta `data` para a raiz do repositório. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.

Após o commit, atualize o site com `Ctrl + F5`.
